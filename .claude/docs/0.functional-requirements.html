4. Detailed functions by moduleChức năng chi tiết theo module

Choose a module to inspect its product boundary and traceability, then expand a function group to see the concrete capabilities it contributes. Module IDs are stable architecture boundaries; function-group IDs are the units used to plan flows and backlog slices.

Chọn một module để xem ranh giới sản phẩm và thông tin truy vết, sau đó mở từng nhóm chức năng để xem các năng lực cụ thể. ID module là ranh giới kiến trúc ổn định; ID nhóm chức năng là đơn vị dùng để lập flow và chia backlog.
