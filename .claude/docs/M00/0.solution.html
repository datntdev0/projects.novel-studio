Edge cases & error handlingTrường hợp biên & xử lý lỗi

  • appRoot not writable (e.g. zip extracted under Program Files): a native error box with the translated APP_DIR_NOT_WRITABLE message, then exit.
  • appRoot không ghi được (ví dụ giải nén zip vào Program Files): hộp thoại lỗi gốc với thông báo APP_DIR_NOT_WRITABLE đã dịch, rồi thoát.
  • Path guard: compare resolved real paths case-insensitively; reject .. escapes, other drives, UNC paths and links pointing outside.
  • Bảo vệ đường dẫn: so sánh đường dẫn thật đã phân giải không phân biệt hoa thường; từ chối thoát bằng .., ổ đĩa khác, đường dẫn UNC và liên kết trỏ ra ngoài.
  • Atomic write: write <name>.tmp, flush, rename over the target; a leftover .tmp is ignored and overwritten next time.
  • Ghi nguyên tử: ghi <name>.tmp, flush, đổi tên đè lên file đích; file .tmp sót lại bị bỏ qua và ghi đè lần sau.
  • Backend dies twice: failed with BACKEND_FAILED; the app keeps working; no further automatic restart in M00.
  • Backend chết hai lần: trạng thái failed với BACKEND_FAILED; ứng dụng vẫn hoạt động; M00 không tự khởi động lại thêm.
  • ffmpeg missing or broken: FFMPEG_MISSING / FFMPEG_BROKEN in system:status and the log; start-up continues.
  • ffmpeg thiếu hoặc hỏng: FFMPEG_MISSING / FFMPEG_BROKEN trong system:status và log; quá trình khởi động vẫn tiếp tục.
