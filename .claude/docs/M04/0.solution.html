Package codec (T02, AD-29)Bộ mã hoá gói (T02, AD-29)

  • Library: fflate 0.8.3 (MIT, no dependencies, about 800 KB unpacked, a few KB of it bundled), used only for its streaming Inflate and its Zip / ZipDeflate writer. It runs unchanged in Node 24 and Chromium.
  • Thư viện: fflate 0.8.3 (MIT, không phụ thuộc, khoảng 800 KB khi giải nén, chỉ vài KB được đóng gói), chỉ dùng Inflate dạng luồng và bộ ghi Zip / ZipDeflate. Nó chạy nguyên vẹn trên Node 24 và Chromium.
  • Our reader in shared/src/core/package/ (about 200 lines) reads the end record and the central directory from a ByteSource, checks every entry against P-8 before any data is read (path, encryption bit, method 0 or 8, ZIP64 fields read), then inflates one entry at a time in 64 KB chunks and counts the bytes that actually come out (AC-73).
  • Bộ đọc của chúng ta trong shared/src/core/package/ (khoảng 200 dòng) đọc bản ghi cuối và thư mục trung tâm từ một ByteSource, kiểm tra mọi mục theo P-8 trước khi đọc dữ liệu (đường dẫn, bit mã hoá, phương thức 0 hoặc 8, đọc trường ZIP64), rồi giải nén từng mục theo khối 64 KB và đếm số byte thực sự sinh ra (AC-73).
  • Byte sources: a file handle in main (fs.promises.open, positional reads), a dropped or chosen File in BrowserBridge (Blob.slice). Sinks: a temporary file renamed on commit in main, an in-memory file map in BrowserBridge.
  • Nguồn byte: một file handle trong main (fs.promises.open, đọc theo vị trí), một File được thả hoặc chọn trong BrowserBridge (Blob.slice). Đích ghi: tệp tạm được đổi tên khi commit trong main, một bảng tệp trong bộ nhớ ở BrowserBridge.
  • Hashes use WebCrypto crypto.subtle.digest('SHA-256'), global in both hosts (the e2e server on 127.0.0.1 is a secure context).
  • Mã băm dùng WebCrypto crypto.subtle.digest('SHA-256'), có sẵn ở cả hai host (server e2e trên 127.0.0.1 là ngữ cảnh an toàn).

Import and export as jobs (F06, F08, F05)Nhập và xuất dưới dạng job (F06, F08, F05)

  • Preview: the host reads every chapter entry once (hash, UTF-8 check, first line, characters) and keeps one session in memory until Start or discard. The renderer re-runs the pure previewChecks(rows, edits, renumber) on every edit; the host runs it again in import:prepare.
  • Xem trước: host đọc mỗi mục chương một lần (mã băm, kiểm tra UTF-8, dòng đầu, số ký tự) và giữ một phiên trong bộ nhớ tới khi Bắt đầu hoặc huỷ bỏ. Renderer chạy lại hàm thuần previewChecks(rows, edits, renumber) mỗi lần sửa; host chạy lại nó trong import:prepare.
  • Job type import: params hold mode, novel id, package path, size and modification time; each item's unit key carries its row plan (entry, number, title, replace, accept bad UTF-8), so a resumed job needs no session. prepare creates the novel row, folder, novel.json and cover for a new novel, or applies the Use new fields for Import more.
  • Loại job import: params giữ chế độ, id truyện, đường dẫn gói, dung lượng và thời điểm sửa; khoá đơn vị của mỗi mục mang kế hoạch của dòng (mục, số, tiêu đề, thay thế, chấp nhận UTF-8 lỗi), nên job chạy tiếp không cần phiên. prepare tạo dòng truyện, thư mục, novel.json và bìa cho truyện mới, hoặc áp dụng các trường Dùng mới cho Nhập thêm.
  • An import item checks that the package still has the same size and time, reads its entry from the package in place, writes the chapter file and upserts the row; a replaced chapter is the same upsert (Q27). The open reader is cached per job.
  • Một mục nhập kiểm tra gói vẫn cùng dung lượng và thời điểm, đọc mục của nó từ gói tại chỗ, ghi tệp chương và upsert dòng; chương bị thay là cùng phép upsert đó (Q27). Bộ đọc đang mở được giữ theo từng job.
  • onEnd of an import: completed without failed items → ready, otherwise → incomplete; then novel.json gets the new chapterCount and library:changed fires. On library open, a novel left in first whose import job has ended is repaired by the same rule.
  • onEnd của job nhập: hoàn tất không có mục lỗi → ready, ngược lại → incomplete; rồi novel.json nhận chapterCount mới và library:changed được phát. Khi mở thư viện, truyện còn ở first mà job nhập đã kết thúc được sửa theo cùng quy tắc.
  • Job type export: one item per chapter writes into a writer session kept per job (<name>.<job id>.tmp in the target folder; novel.json and cover first). On resume without a live session it is rebuilt from the completed items. The last item closes the archive and renames it: over the target for Replace, to the first free -2, -3 name for Keep both. onEnd of a cancelled export deletes the temporary file.
  • Loại job export: mỗi chương một mục ghi vào một phiên ghi giữ theo job (<name>.<job id>.tmp trong thư mục đích; novel.json và bìa trước). Khi chạy tiếp mà không còn phiên, phiên được dựng lại từ các mục đã hoàn tất. Mục cuối đóng tệp nén và đổi tên: đè lên đích khi Thay thế, sang tên trống đầu tiên -2, -3 khi Giữ cả hai. onEnd của job xuất bị huỷ xoá tệp tạm.
  • Rerun: import and export declare rerun: 'screen', so the Task Center opens the import start dialog through import:openRerun (AC-57) or the export dialog filled from the job; Rerun is disabled when novelDeleted is true (AC-45).
  • Chạy lại: import và export khai báo rerun: 'screen', nên Trung tâm tác vụ mở hộp thoại bắt đầu nhập qua import:openRerun (AC-57) hoặc hộp thoại xuất điền sẵn từ job; Chạy lại bị tắt khi novelDeleted là true (AC-45).

  • One top folder is unwrapped only when every entry shares it and nothing sits beside it (P-1). Entry names use UTF-8 when the UTF-8 flag is set or the bytes are valid UTF-8; otherwise they are shown with replacement characters, and the number still comes from the leading digits.
  • Một thư mục bao ngoài chỉ được mở bỏ khi mọi mục cùng nằm trong nó và không có gì bên cạnh (P-1). Tên mục dùng UTF-8 khi có cờ UTF-8 hoặc byte là UTF-8 hợp lệ; nếu không, tên hiện kèm ký tự thay thế, và số vẫn lấy từ các chữ số đầu.
  • The package is read in place, never copied: if it is moved, deleted or changed during the run, the item fails with PACKAGE_NOT_FOUND or PACKAGE_CHANGED, a fast-complete error, so after its retries the job ends “Completed early”, the rest stay pending and the novel is “Import incomplete” (Q-5, AC-55).
  • Gói được đọc tại chỗ, không bao giờ sao chép: nếu nó bị chuyển, xoá hoặc thay đổi khi đang chạy, mục lỗi với PACKAGE_NOT_FOUND hoặc PACKAGE_CHANGED, một lỗi nhóm hoàn tất sớm, nên sau các lần thử lại job kết thúc “Hoàn tất sớm”, phần còn lại giữ chờ xử lý và truyện là “Nhập chưa xong” (Q-5, AC-55).
  • An import passes no chapter range; the import type's overlap rule treats any active import of the same novel as overlapping (AC-56), whatever its numbers.
  • Job nhập không truyền khoảng chương; quy tắc chồng lấn của loại nhập coi mọi lần nhập đang hoạt động của cùng truyện là chồng lấn (AC-56), bất kể số chương.
  • Covers: type is checked by file signature (PNG, JPEG, WebP) and completeness (PNG end chunk, JPEG end marker, RIFF length), size ≤ 10 MB; the new cover.<ext> is written atomically before the old one of another extension is removed. The renderer loads ns-cover://<id>?v=<hash> in Electron and a data URL in BrowserBridge.
  • Bìa: loại được kiểm tra bằng chữ ký tệp (PNG, JPEG, WebP) và độ đầy đủ (chunk kết thúc PNG, dấu kết thúc JPEG, độ dài RIFF), dung lượng ≤ 10 MB; cover.<ext> mới được ghi nguyên tử trước khi xoá bìa cũ có đuôi khác. Renderer tải ns-cover://<id>?v=<hash> trong Electron và data URL trong BrowserBridge.
  • Language detection counts scripts in the first 20 KB of text: kana → ja, Hangul → ko, Han → zh, Latin with Vietnamese letters → vi, other Latin → en. Characters are non-whitespace code points.
  • Nhận diện ngôn ngữ đếm hệ chữ trong 20 KB văn bản đầu: kana → ja, Hangul → ko, chữ Hán → zh, chữ Latin có chữ cái tiếng Việt → vi, Latin khác → en. Ký tự là các code point không phải khoảng trắng.
  • If files cannot be removed after a delete (for example a file open in another program), the novel is already gone from the library; a warning toast names the folder and the log keeps the paths.
  • Nếu không xoá được tệp sau khi xoá truyện (ví dụ tệp đang mở trong chương trình khác), truyện đã biến mất khỏi thư viện; toast cảnh báo nêu thư mục và log giữ các đường dẫn.
  • Export writes each chapter's stored text unchanged, so a title edited in the preview that differs from the first line is not carried by a re-import (P-4); AC-61 does not include titles.
  • Xuất ghi nguyên văn bản chương đã lưu, nên tiêu đề sửa trong bản xem trước khác dòng đầu không được mang theo khi nhập lại (P-4); AC-61 không bao gồm tiêu đề.
  • “Discard import changes?” on app close joins the M03 close path: the renderer asks its dirty import screen first, then the active-jobs dialog.
  • “Huỷ bỏ thay đổi nhập?” khi đóng ứng dụng nối vào luồng đóng của M03: renderer hỏi màn hình nhập đang có sửa đổi trước, rồi tới hộp thoại job đang chạy.
