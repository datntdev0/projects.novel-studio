## Conventions

- **Level 1 task (`T<n>`)** = exactly one commit. Tasks run **sequentially** in the order listed.
  Commit message: `<type>({{FLOW_NAME}}): <task title> [T<n>]`
- **Level 2 subtask (`T<n>.<m>`)** = unit of work for one subagent. Siblings may run **in parallel**,
  so they must touch **disjoint files**. If two subtasks need the same file, merge them or split the task.
- Every task ends with a **reviewer** pass before the commit. Findings go to [2.review.md](2.review.md).
- The last task is always the **automation test task** owned by the verifier (playwright-cli).
- Status values: `todo` · `doing` · `review` · `done` · `blocked`
- **Jira**: each `T<n>` maps to one Jira Subtask under the item's Story / Task; `T<n>.<m>` is not tracked in Jira. See `skills/tool-atlassian`.
